# Rakku

Aplikasi Beli & Baca Manga, Nonton Anime Sub Indo, Komunitas & Virtual Coin.

## Menjalankan Secara Lokal

**Prasyarat:** [Android Studio](https://developer.android.com/studio)

1. Buka Android Studio
2. Pilih **Open** dan arahkan ke folder project ini
3. Biarkan Android Studio menyelesaikan sinkronisasi project
4. Jalankan aplikasi di emulator atau perangkat fisik
